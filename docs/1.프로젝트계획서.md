# 프로젝트 계획서

## 1. 프로젝트 개요

### 1.1 프로젝트명
- **AskNote** (수업 자료 기반 AI 학습 도우미)

### 1.2 프로젝트 목적
- 학생이 공부하려는 수업 자료(교안 · 실습 가이드 · 정리 노트)를 **개인 계정에 업로드**하면, 질문에 대해 **자료 내용을 근거로 한 답변**을 출처(문서명 · 페이지)와 함께 제공한다
- 답변은 자료 범위 안에서만 만들고, 자료에 없는 내용은 추측하지 않는다
- 가이드 권장 범위(엔티티 3\~4개, 화면 4\~6개, RAG 질의응답 1개)를 넘지 않게 기능을 최소화하고, 남는 시간은 3대 목적에 쓴다
  - ① **LLM 연동**: Backend → FastAPI(LangChain RAG) → 답변이 화면까지 스트리밍(SSE)으로 전달
  - ② **안전한 백엔드**: OWASP Top 10 기준 자체 점검, 취약점 3건 이상 재현 → 조치 → 재확인 (RAG 검색까지 소유자 검증 적용)
  - ③ **배포**: 전 구성요소 Docker화, GitHub Actions 이미지 빌드 · Push, AWS EC2에 Compose로 배포

### 1.3 프로젝트 기간
- 시작일: 2026-11-05 (목) – 오전 이론 수업 후 오후 조 편성 · 킥오프
- 종료일: 2026-11-13 (금) – 산출물 제출 및 발표

### 1.4 해결하려는 문제
- 복습하다 모르는 부분이 생기면 여러 자료를 하나씩 열어 해당 내용을 찾아야 해서 시간이 오래 걸린다
- 범용 AI에 물으면 수업에서 배운 방식 · 버전과 다른 답이 나오거나 근거 없는 답(환각)이 섞여, 수업 내용 기준으로 공부하기 어렵다

### 1.5 범위

| 구분 | 포함 | 제외 |
|------|------|------|
| 자료 업로드 | 개인 계정에 **PDF 파일** 업로드 | PDF 외 형식(MD · PPTX · DOCX), 노션 · 구글 드라이브 자동 동기화, 스캔 PDF(OCR) |
| 답변 | 내 자료 기반 RAG 답변 스트리밍 + 근거 출처(문서명 · 페이지), 답변 피드백(도움됨 / 도움 안 됨) | 과목 · 문서 선택 필터, 웹 검색(Tavily) · LangGraph (가산 과제), 퀴즈 생성 |
| 자료 관리 | 내 자료 목록 · 삭제, **답변은 본인 계정에 업로드한 자료만 근거로 생성** | 자료 공유 · 스터디 그룹 자료함 |
| 사용자 | 회원가입 · 로그인, 질문 기록 목록(페이징, 질문 · 답변 · 출처 · 피드백 표시) | 소셜 로그인, 질문 기록 삭제 |
| 관리자 | 관리자 화면 없음. ADMIN 역할은 Actuator 접근 제한에만 사용, 계정은 환경 변수로 생성 | 대시보드, 통계, 회원 관리 |

## 3. 기술 스택

- **Backend**: Java 17, Spring Boot 4.0.x, Spring Security 7.x, Spring Data JPA, JJWT, WebClient(SSE 중계), Flyway, Bean Validation, Maven
- **Frontend**: React 19.3.x + Vite, React Router, Zustand, axios + fetch 스트리밍, Tailwind CSS
- **AI/ML**: Python 3.12, uv, FastAPI(SSE), LangChain(LCEL, PromptTemplate, OutputParser, PyPDFLoader, RecursiveCharacterTextSplitter), (선택) LangSmith
  - LLM: 개발 Groq / 배포 OpenAI · 임베딩: 개발 Ollama `bge-m3`(1024차원) / 배포 OpenAI `text-embedding-3-small`(1536차원) — 환경 변수(`LLM_PROVIDER` · `LLM_MODEL` · `EMBEDDING_PROVIDER` · `EMBEDDING_MODEL`)로만 전환
- **Database**: MariaDB 10.11(관계형), Flyway, Chroma(벡터 DB, 볼륨 영속화, 메타데이터: 소유자 uuid · 문서 id · 문서명 · 페이지)
- **Security**: BCrypt, JWT(Access 짧게 + Refresh SHA-256 해시 · 회전), CSP · CORS 제한, 감사 로그, Burp Suite, SBOM(CycloneDX), `npm audit`
- **Infrastructure**: Docker, Docker Compose, GitHub Actions(Docker Hub Push), AWS EC2(운영진 제공 개인 계정) / (가산) GCP GKE

### 보안 요구사항 (필수)
- [ ] 인증/인가 (JWT, 리소스 소유자 검증)
  - [ ] 토큰 subject는 회원 **uuid** (email · 숫자 id 사용 안 함)
  - [ ] Access Token 짧게(15분), Refresh Token은 DB에 SHA-256 해시로 저장 · 재발급 시 회전 · 로그아웃 시 폐기

## 6. 성공 기준

- 로컬과 EC2 배포 환경 모두에서 **회원가입 → 로그인 → 자료 업로드 → 질문 → 내 자료 기반 답변 스트리밍(출처) → 기록 조회**가 끝까지 동작한다
- 다른 사용자의 자료가 답변 · 출처에 쓰이지 않고, 다른 사용자의 자료 삭제 · 답변 피드백이 차단되며(403), 목록에는 본인 데이터만 나온다
- 보안점검서에 취약점 3건 이상의 재현 → 조치(전/후 코드) → 재확인 근거(Burp 캡처 · 응답 코드 · 로그)가 있고, `fix(security): ...` 커밋으로 연결된다
- Git 이력과 소스에 키 · 비밀번호 · 수업 자료 파일이 없다
- DB · AI Module 포트가 외부에 노출되지 않는다
- GitHub Actions가 이미지 3종의 빌드 · Push를 자동 수행한다
- 산출물 9종의 기술 스택 · 포트 · API 경로가 서로 일치한다

**여유가 있으면 (선택)**
- 소유자 검증 · 로그인 잠금 테스트 코드 1\~2개
- 평가 질문셋(질문 · 기대 자료)으로 출처 적중률 측정, LangSmith 추적
- MD 형식 지원
- Refresh Token을 HttpOnly 쿠키로 전환 + EC2 HTTPS 적용
